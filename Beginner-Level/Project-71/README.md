## 🎯 Overview

A static weather dashboard card layout showing the current condition, temperature, key details (humidity, wind, feels-like, UV index), and a 5-day forecast strip. All weather values are hardcoded — this project focuses purely on layout, iconography, and displaying structured data, without any live weather API. The only dynamic part is today's date, generated from the browser's own clock.

## ✨ Features

- 🌡️ **Main weather display** — large temperature and condition icon
- 📅 **Live current date** — generated from the `Date` object, not hardcoded
- 📊 **Detail grid** — humidity, wind speed, feels-like temperature, and UV index
- 📆 **5-day forecast strip** — day name, icon, and temperature for each upcoming day
- 🎨 **Card-based layout** — a self-contained weather widget suitable for a dashboard

## 🎓 Learning Outcomes

This beginner project teaches:

1. **Date object basics** — reading `getDay()`, `getDate()`, and `getMonth()` to build a readable date string
2. **Array indexing for lookups** — using the numeric result of `getDay()`/`getMonth()` directly as an index into a names array
3. **Rendering a list from an array of objects** — looping over `FORECAST_DATA` with `forEach` to build repeated UI blocks
4. **Template literals for structured markup** — building each forecast day's HTML from object properties
5. **CSS Grid for evenly spaced detail cards** — a simple 4-column grid for the stats row
6. **Separating static layout from dynamic content** — most of the card is fixed HTML, while only the date and forecast are generated by JavaScript

## 🛠️ Technologies Used

- **HTML5** — Semantic structure
- **CSS3** — Flat neon-themed card layout, CSS Grid for details, flexbox for the forecast row
- **JavaScript ES6+** — `Date` object, array iteration, template literals

## 💻 Usage Guide

1. Open `index.html` in a browser
2. The card displays a fixed sample weather condition along with today's actual date
3. Scroll to the bottom of the card to see the 5-day forecast strip
4. No interaction is required — this is a display-only layout project

## 🔍 Code Walkthrough

### Building a readable date string

```javascript
function displayTodayDate() {
  const today = new Date();
  const dayName = ['Sunday', 'Monday', ...][today.getDay()];
  const monthName = MONTH_NAMES[today.getMonth()];
  const date = today.getDate();

  dateText.textContent = `${dayName}, ${date} ${monthName}`;
}
```

`getDay()` returns a number from 0 (Sunday) to 6 (Saturday), and `getMonth()` returns 0 (January) to 11 (December) — both used directly as array indices to look up their human-readable names, avoiding a long if/else chain.

### Rendering the forecast strip from data

```javascript
FORECAST_DATA.forEach(dayData => {
  const dayBlock = document.createElement('div');
  dayBlock.classList.add('forecast-day');

  dayBlock.innerHTML = `
    <span class="forecast-name">${dayData.day}</span>
    <span class="forecast-icon">${dayData.icon}</span>
    <span class="forecast-temp">${dayData.temp}</span>
  `;

  forecastRow.appendChild(dayBlock);
});
```

Keeping the forecast as an array of plain objects (rather than hardcoding five separate HTML blocks) means adding, removing, or reordering forecast days only requires editing the data array — the rendering logic stays the same.

## 🎨 Customization Guide

### Connect a real weather API

Replace `FORECAST_DATA` and the hardcoded current conditions with a `fetch()` call to a weather API (e.g. OpenWeatherMap), mapping the response's condition codes to matching emoji or icon assets.

### Add unit toggling

Add a °C/°F switch that recalculates and re-renders all temperature values using the standard conversion formula.

### Swap emoji for real icon assets

Replace the emoji weather icons with SVG or PNG icon sets for a more polished, consistent look across platforms (emoji rendering varies by OS).
